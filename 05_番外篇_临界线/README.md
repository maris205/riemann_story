# 番外篇 临界线（Critical Line）

一篇关于未来黎曼猜想求解方式的科幻短篇。人物、事件与未来情境均属文学虚构，含戏仿与讽刺，不作为前四篇数学与历史论述的依据。

全篇已按北极中微子通信与三个月期限重写，以庄园的最后二十四小时、黎明的简报与北极的寂静收尾。[设定与科学底稿](../资料/番外_临界线/README.md)。
