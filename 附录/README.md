# 我们的两次动力学实验

这一节选取Liang Wang于2026年发表的两篇工作，作为动力学直觉如何变成可比较模型的案例。两篇论文从简单的二次映射出发，一篇观察素数分布的统计形态，一篇进一步尝试零点的谱对应。它们可以成为第三篇第12节中一段有具体计算、有自我检验的叙事。

- [从混沌映射重现素数统计](01_从混沌映射重现素数统计.md)
- [从谱的吻合走向留出检验](02_从谱的吻合走向留出检验.md)

两次实验的共同收获，是把“看起来相像”的直觉变成能够比较、能够质疑的模型。论文所披露的Gemini 3 Pro辅助代码、探索与文字工作，是研究过程的一部分；这里的数学结论仍以公开假设、计算方法和检验结果为准。
