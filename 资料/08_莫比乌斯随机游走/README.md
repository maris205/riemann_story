# 08 莫比乌斯随机游走：研究底稿

核对日期：2026年10月22日。对应[正文](../../02_第二篇_经典方法的新长征/08_莫比乌斯随机游走.md)。

## 本章主线

一个确定的走路游戏 → 平方根抵消与RH → 过强的梅滕斯围栏失败 → 从总路程转向短窗口 → 从平均转向相关 → 熵递减与埃尔德什偏差 → 图、谱与后续进展。

人物线以马托迈基、拉齐维乌的合作为21世纪重心，连接陶哲轩与埃尔德什的老照片、2015年博客讨论。20世纪材料只交代必要来路。正文两条公式，完整定义与限制放在底稿。
