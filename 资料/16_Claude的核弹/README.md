## 视频改编提示

先用发现记录建立悬念，再问“为什么半个世纪前已有同一个数字”；不要开场连报五个比例。矩阵部分可用两组数字1、1、1、1与4、0、0、0做动画；离线配对画为空心假设点。贝塞尔部分先画垂直投影，再过渡到函数空间。
