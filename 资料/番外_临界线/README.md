### 2026年10月24日：尾声改为证伪反转（覆盖早先成立结局）

按作者新设想，将结局由证明RH成立改成发现一组离线零点并严格证伪。秘书非专业，仍喊“黎曼假设被证明了！”；新闻标题写“解决”，简报正文揭示证伪，形成口头转述与专业结论的反差。第01节已明确证明或证伪均可通过文明评级，不需更改验收规则，也不在结尾补解释。

数学核查依据：[NIST DLMF §25.10(i)](https://dlmf.nist.gov/25.10) 中非平凡零点关于实轴及实部1/2直线的对称性。若上半平面有β+iγ且β≠1/2、γ>0，则相应有1−β+iγ，以及它们的两个共轭零点。正文“一对”限定上半平面，并交代下半平面的共轭伙伴；全平面是四个不同位置。使用“异常”作文学描述，“奇异非平凡零点”并不是这里援引的标准分类。

与第03节的兼容条件：设这组反例距临界线不超过0.000001，高度在已核验前10¹³个零点的区间之外。有限个离线零点占比仍趋零，因此不冲突于“渐近100%”。其余在线零点的谱对应不能证明RH；必须对异常因子单独处理，并严格确认例外确实偏离临界线。可设想先从完成ζ函数中分离含这组零点的有限因子，再为余下部分构造自伴谱解释，这是剧情框架，不是已知数学构造。

这只是逻辑上与所列约束相容的科幻设定；没有证据支持实际存在这组零点，不能由“尚未排除”推断其出现概率。正文所说Lean核验也是虚构事件。
