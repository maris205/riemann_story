## 写作约定

[数学科普写作约定](数学科普写作约定.md)记录本系列的文风、读者定位和工作顺序。相同流程也已安装为本地Codex技能 `math-popular-writing`；技能本体位于用户技能目录，项目里的这份约定与章节底稿可随仓库保存。

引用史实前，先看卡片的证据层级和阅读范围。“找到链接”“读过摘要”“核对过全文相关段落”是三种不同状态。作者比喻和幽默旁白不应在视频改编时变成数学家的原话。
