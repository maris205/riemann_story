## 选材决定

2026年新预印本确有明确构造，但其1/4维数由“每次保留2段、每段缩小到1/16”决定，不是素数分布的新维数定律。相比之下，2025年正式发表的连分数论文更能说明素数间隔如何进入精细几何，故正文详写后者。未检索到的文献不等于不存在；本稿不宣称穷尽所有最新研究。

原章的复维数极点图和逆谱抵消图撤出正文以减轻负担，文件保留。保留康托弦泛音图；新增四幅原创计算图和一张真实场景照片。全章仅三处独立公式，无行内美元符号公式。
