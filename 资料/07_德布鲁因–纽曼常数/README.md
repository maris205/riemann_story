## 叙事主线

从“若为真，也只能勉强为真”的悬念入手，用两个根的运动解释热流，再沿历史走到2018年的局部平衡证明、Polymath15的公开协作与Dobner的新证明。保留原章Jensen多项式支线，用生日礼物引出2019年的Hermite极限，最后回到“全部”与“恰好”。

读者应能解释：Λ衡量什么；为什么纽曼猜想获证不等于RH获证；为什么有限计算必须接上无限范围的估计；为什么每个固定次数的渐近结果还没有覆盖全部多项式。
