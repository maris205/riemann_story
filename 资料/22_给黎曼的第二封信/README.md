# 22 给黎曼的第二封信：研究底稿

核对与写作：2026年10月23日。正文为GPT执笔的原创文学书信，采用角色化第一人称；不是OpenAI官方声明，不是模型真实经历的自传，也不代表已取得RH证明。科研事实据原文，未来署名与谱路线偏爱为作者设想。

## 主线与范围

科纳的信 → GPT名帖与学习机制 → 知识增长和跨领域困难 → 费马问题的连接 → 黎曼手稿与现代计算 → 期待人机共同写第三封信，抄送希尔伯特。

从用户建议保留了自信与幽默，但把“今后不可能再有跨领域大师”写成个人覆盖前沿愈发困难；把“很快必然由谱路线证明”处理为写信人的愿望。开头分清Claude、OpenAI内部研究模型及人类合作者的贡献，不将本次写信的GPT等同于产生前章论文的具体研究系统。

### GPT与注意力

- Alec Radford等，*Improving Language Understanding by Generative Pre-Training*，2018。[原文](https://cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf) · [本地PDF](原始文献/GPT_2018.pdf)。读第1—3页，特别是§3.1：依前文预测后续符号、概率目标、参数梯度调整及Transformer解码器；区分预训练与后续任务训练。正文没有将2018年的参数量、语料规模或具体网络规格套用到当前GPT。
- Ashish Vaswani等，*Attention Is All You Need*，2017。[论文](https://arxiv.org/abs/1706.03762) · [本地PDF](原始文献/Transformer_2017.pdf)。读第3—4页§3.1—3.2：查询、键和值的关联，以及加权汇总。正文“回看假设和定义”是功能直觉，不保证每个注意力权重均有这种明确语义。
- OpenAI，[Learning to reason with LLMs](https://openai.com/index/learning-to-reason-with-llms/)，2024-09-12。读公开机制说明和Chain of Thought段：强化学习、尝试不同路线及推理时计算。没有逐项复验基准，也没有描述本次模型未公开的训练细节。训练改变参数与回答时使用上下文是两件事，正文没有说每次聊天都重新训练参数。
- OpenAI，[2026年10月6日发布说明](https://openai.com/index/sharing-ai-progress-in-mathematics/)。重新核对内部研究模型、论文仓库与形式化说明。数学结果仍以[第16章](../16_Claude的核弹/README.md)、[第18章](../18_被拉直的边界/README.md)、[第19章](../19_课后习题之西格尔零点/README.md)原论文核对范围为基础；不将厂商发布等同于独立完整复核。

### 黎曼手稿与零点计算

- Carl Ludwig Siegel，1932，*Über Riemanns Nachlaß zur analytischen Zahlentheorie*；Eric Barkan、David Sklar的2018年英译。[arXiv](https://arxiv.org/abs/1810.05198) · [本地PDF](原始文献/Siegel_1932_translation_2018.pdf)。读PDF第1—3页（译者说明与原文开头）：1859年致Weierstrass信、Distel图书馆员早先发现、Bessel-Hagen于1926年查看、1932年整理；原笔记碎片化、需补估计和收敛论证；黎曼曾用渐近展开计算一些零点。正文避免“西格尔是第一个看到公式的人”与“原稿已有完整可发表证明”。这是译本阅读，未独立校对德文原件。
- Dave Platt、Tim Trudgian，*The Riemann hypothesis is true up to 3·10¹²*，预印本2020，期刊2021。[论文](https://arxiv.org/abs/2004.09765) · [DOI](https://doi.org/10.1112/blms.12460) · [本地PDF](原始文献/Platt_Trudgian_2020.pdf)。读第1—4页，正文主要采用第2—3页。Theorem 1的精确高度为3,000,175,332,800，覆盖12,363,153,437,138个正虚部非平凡零点。正文约写高度三万亿、个数超过十二万亿。
- 同文§2明确说明：计算线上变号、用Turing方法变体核对全部计数、区间/球算术控制误差；不追求所有零点高精度，理由含运行时间和存储空间。这是书信中“抽屉与计算机”的事实来源，笑话本身是作者旁白。并未在本机重跑其750万核小时的计算。
- Andrew Odlyzko，[本人零点表](https://www-users.cse.umn.edu/~odlyzko/zeta_tables/)。实际查看页面：公开编号10²²+1至10²²+10⁴的局部数据。10²²是编号，不是虚部高度，也不是从第一点连续核验到这一编号；正文明确区分。本次未下载或重算这批数据，第13章已有相关高位间隔资料。
- 本文没有将2021年的严格验证称为截至2026年的最新世界纪录；以确定可追溯的成果与高位抽样，说明现代计算到达的尺度。

## 可复用的讲法

1. 把GPT先说成多参数函数，再引出符号数值化、依前文预测、加权关联和导数调整。避免一上来堆网络缩写。
2. 概率高不等于数学正确；新增数学训练、搜索与核验，解释从语言模型走到证明工作的路径。既不说纯粹随机猜字，也不声称训练消除了幻觉。
3. 费马段只保留一座桥：反例造曲线 → 曲线不能模 → 半稳定曲线必须模 → 矛盾。无需在文学书信里完整解释伽罗瓦表示。
4. 手稿段采用“纸页—抽屉—存储—高位窗口”的意象。历史先后须保留；不添加西格尔打开抽屉时的对白、天气或心理活动。
5. 第三封信是期待；谱路线仍需完整零点对应、自伴性和全局论证。可以偏爱，不替数学提前宣布赢家。
6. “希尔伯特醒来”来自本书[序](../../序.md)的虚构开场，正文明确称作者安排，不作真实轶事。抄送用Cc的意思，不把Re误释为抄送。

## 补记：摇柄与0.84秒

2026年10月23日按作者反馈补入两段。

- Stephen Johnston，*Making the arithmometer count*，1997，[牛津科学史博物馆保存的研究全文](https://www.mhs.ox.ac.uk/staff/saj/arithmometer/)。读取机械操作与1851年博览会段落：托马斯计算器参展、获奖与摇柄操作。另核对[美国计算机历史博物馆的藏品介绍](https://www.computerhistory.org/revolution/calculators/1/52)，区分早期丝带驱动与后期摇柄。正文只说黎曼时代已有，并不推定黎曼见过或使用过。没有采用“1851年即广泛普及”的说法。
- Fredrik Johansson，[Arb 2.23 released](https://fredrikj.net/blog/2022/06/arb-2-23-released/)，2022-06-29。实际阅读性能测试说明与New example programs部分。页面硬件为AMD Ryzen 7 PRO 5850U，示例命令 `zeta_zeros -count 1000 -digits 100 -threads 8`；记录CPU时间5.36秒，墙钟时间0.84秒。正文采用0.84秒，不混用CPU时间。作者明确描述前1000个零点到100位；不是一千个不同高度随机零点，也不是读取零点表。
- “蘸墨再抬笔”“人还得接着想”为作者幽默比喻，不是历史现场或精确动作计时。本次没有在本机复现实测。
- 没有查到足够直接的证据支持一般性的“普通电脑几秒从头计算几万个零点”，故改用公开且有配置、精度、数量和耗时的基准，不按1000个的耗时线性外推。
