# 06 临界线上的零点比例：研究底稿

核对日期：2026年10月22日。对应[正文](../../02_第二篇_经典方法的新长征/06_临界线上的零点比例.md)。

## 这一章想讲什么

从“有无穷多个”走到“能保证一个比例”，再解释磨光因子为何能改善保证。20世纪前史压缩交代；21世纪重点放在2010—2011年的双片构造、2018年前后的误差分析及2018—2020年的新磨光结构。2026年的67.25%只作通往第四篇的路标。

读者应带走三个认识：有限范围全部在线，与无穷范围至少四成在线，是两类保证；磨光因子借有限抵消改善平均估计；占比趋于100%仍可能遗漏例外。
