## 时间线

| 时间 | 节点 | 不应混同的对象 |
| --- | --- | --- |
| 1859 | 黎曼以ζ零点研究素数计数 | 误差界不等于知道每颗素数的地址 |
| 20世纪30年代 | Cramér随机素数模型 | 模型抽样不是真实素数生成机制 |
| 1963、1976 | Lorenz对流模型；May离散种群模型 | 确定性动力系统的混沌 |
| 1985 | Kahane建立GMC理论 | 对数相关场的指数权重 |
| 2016／2020 | Saksman–Webb预印本／正式发表 | 真实ζ的广义函数极限；另有随机模型测度结果 |
| 2017／2020 | Harper低阶矩与Helson猜想 | 随机乘法函数，非确定的莫比乌斯和 |
| 2018 | Torquato等研究素数散射 | 特定极限；HL素数对猜想是条件 |
| 2025 | Gorodetsky–Wong简证；Wang–Xu条件性算术推进 | 简证损失部分精细结果；后者须GRH和Ratios |
| 2025年9月11日 | Harper报告与Saksman、Webb的合作 | 临界模平方窗口积分；讲稿标in preparation |
| 2026年6月27日 | Harper–Soundararajan–Xu短区间论文 | Steinhaus模型，经适当归一化的复高斯极限 |

## 最新状态的措辞

本轮检查2025年Simons会议页、讲稿、相关作者机构页、arXiv题名及作者组合检索，未找到与该报告一一对应、可确认版本的完整正式论文。正文采用“2025年的报告／讲稿报告”，不把未检索到写成不存在，也不暗示已独立审查完整证明。已发表的2020年结果分别记述。

2026年其他模型方向还有延伸，例如Duplantier、Gayrard、Saksman的[随机ζ函数积分均值谱](https://arxiv.org/abs/2603.26507)。本轮只查到摘要及记录，未深入阅读全文，未作为正文技术依据；它不能替代2025年真实ζ临界模平方结果。

旧版的零点间距配图从正文撤下，以免把函数值统计与零点间距混作一事；旧文件保留。新稿没有把“素数由低维混沌生成”写成结论，低维模型留给后续专节。
