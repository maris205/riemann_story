## 主线与数学条件

1. **半步之遥。** 若对每个ε>0，ζ在Re(s)>1/2+ε均无零（s=1为极点另处理），且覆盖全部高度，那么任何实部1/2+δ的假设零点都被ε=δ/2排除。函数方程的对称性再处理左侧。这不是从有限次改进自动推出的结论。
2. **抵消。** 100+(−99)=1，而|100|+|−99|=199。例子解释取绝对值会丢失相位或符号信息；没有将它冒充具体数论证明中的唯一瓶颈。AI寻找权重、分解与障碍是展望。
3. **乐器。** 定义ξ(s)=s(s−1)π^(−s/2)Γ(s/2)ζ(s)/2，Ξ(z)=ξ(1/2+iz)。RH等价于Ξ所有零点均实。需要在不预设RH的前提下建立完整的谱对应，处理重数、可能多余的谱、极限及正则化。例如适当谱行列式等于Ξ乘一个无零因子，方可利用自伴谱实性。正文省略公式，但保留“全部”和边界条件。
4. **弦的端点。** 两端固定与一端固定、一端自由的弦，边界条件不同，允许的固有频率也不同。这是定义域重要性的比喻；没有说弦本身实现了黎曼谱。
5. **回声。** 在Re(s)>1，−ζ′/ζ=Σ_p Σ_{k≥1}(log p)p^(−ks)。写s=σ+it，振荡项为exp(−it k log p)，故log p对应基本周期，k log p对应重复。log4=2log2，log8=3log2，是可演示的简单例子。进入临界线上的显式公式须用合适的平滑、测试函数或分布解释，不能把原绝对收敛级数直接逐项代入。周期、振幅、符号与平均项均须匹配；仅贴素数标签不足以产生目标迹公式。
6. **岔路。** 留出预测失败和统计不匹配通常只是调查线索；GUE预期也不能整体当成已证必要条件。严格否证须与已证必要条件冲突，并有严格误差包络。排除一个候选或参数盒不等于排除整条谱路线。
