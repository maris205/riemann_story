- 推荐位置：第16章“一对离线零点能提供几个正方向”段末，进入“两本矩阵账簿”之前。
- 图注：在有限测试空间中，一个简单在线零点提供一个秩至多为一的正半定贡献；一对假设的离线镜像零点占用至少两个按重数计算的名额，却至多提供一个正方向。迹与平方和的整体估计，再结合零点块结构，迫使大量零点既单又在线。图形只解释计数机制，不是测得的零点分布。

## multiplicity_counting_units.png / .svg（第16章）

**放置：** “同一框架还给出不同零点个数的下界”段落后。

**图注：** 假设三个在线位置的重数分别为1、2、3，则按重数共六个名额，不同零点只有三个，简单在线零点只有一个。三个问题使用不同分子，不能混写。论文分别给出简单在线比例2−R与不同零点比例(3−R)/2的渐近下界。

**边界：** 所有点均为教学假设，非ζ实测零点。两种下界来自同一框架的不同计数论证，不能仅由简单在线比例推出不同零点比例，因为其余重数没有“至多二重”的保证。优化窗R≈1.3274992963205885，分别得0.6725007036794115与0.8362503518397058。数值不是固定有限高度必须达到的比例。

**依据：** https://arxiv.org/html/2608.13637v2 ，Theorem A、§1.1定义、§1.2末尾对不同零点数的独立不等式链。本轮已读取这些部分；没有复制论文版式。

# 第15章原创概念图

## kakeya_dimension_volume.png / .svg

建议位置：第15章「一根针与整个方向空间」，在解释「零体积与满维数能够同时发生」的段落之后。

建议图注：**一根针转过所有方向，集合能有多小？** 左侧仅绘出72个不同方向的单位线段，说明方向与重叠的几何直觉；这个有限并集维数为1，并不是挂谷集合或零体积构造。右侧用单位立方体作参照，区分体积与维数。真正的三维挂谷集合在每个方向含有一条单位线段；它可以具有零体积，但王虹与Joshua Zahl在2025年证明，其Hausdorff维数和Minkowski维数均为3。

来源：Hong Wang and Joshua Zahl, *Volume estimates for unions of convex sets, and the Kakeya set conjecture in three dimensions*, arXiv:2502.17655v1 (2025), §1，Theorem 1.1，第3页。https://arxiv.org/abs/2502.17655 。论文将Kakeya集合定义为含每个方向单位线段的紧集；本图按这个标准定义理解。定理核验日期2026-10-19。

零体积挂谷集合是经典Besicovitch现象，并非2025年的新增结论。图形完全原创，没有描摹论文插图，没有模拟真实最优构造，没有提供证明；针的显示线宽只是可视化，不是集合的数学厚度。针的端点CSV可复算。有限采样本身不支持任何极限维数推断。旋转标题指方向覆盖，不要求一根针在集合内部连续运动。

本图只引用2025年几何定理，不把获奖年份当数学来源，不涉及RH的解决。单位立方体的体积为1，Hausdorff和盒维数均为3。零体积集合的存在和满维数的必然性是两个不同命题。

输出：2880×1440 PNG、字体转路径的SVG，原始Python及线段端点数据见[源程序目录](../src/README.md)。本项目未为本图和程序另行新增开放许可证。
