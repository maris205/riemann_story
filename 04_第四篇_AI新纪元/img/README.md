## weil_pair_budget.png / .svg

- 推荐位置：第16章“一对离线零点能提供几个正方向”段末，进入“两本矩阵账簿”之前。
- 图注：在有限测试空间中，一个简单在线零点提供一个秩至多为一的正半定贡献；一对假设的离线镜像零点占用至少两个按重数计算的名额，却至多提供一个正方向。迹与平方和的整体估计，再结合零点块结构，迫使大量零点既单又在线。图形只解释计数机制，不是测得的零点分布。
- 数学底线：压缩可能退化，因此不用“每一对必定留下一个正和一个负特征值”的说法。一般不等式限制的是总量，不是根据单个矩阵特征值定位某颗零点。图中只列两类代表，不声称覆盖重零点的全部记账。精确证明还处理归一化、测试窗、高度边缘、尾项及重零点。
- 结果范围：N按重数统计，R为窗函数的二阶矩常数。N_simple,on ≥ (2−R−o(1))N为渐近下界。程序计算R≈1.3274992963205885，2−R≈0.6725007036794115。剩余部分未被这个下界保证，不是已经找到的离线零点。
- 依据：Alpöge–Furman，2026预印本v2，§1.2、§3、§4，https://arxiv.org/html/2608.13637v2 。本次读取§1.2的块结构、迹范数估计及不等式链；不声称独立复核整篇证明。
- 替代文本：左侧一颗在线点占一个名额，连接一个正方向符号；右侧两颗空心假设离线点占至少两个名额，连接至多一个正方向。下方迹、平方和与块结构共同给出渐近计数下界。

## curved_and_fixed_regions.png / .svg

- 推荐位置：第17章“一条边界与一个百分数”中，说明闭带1/8≤Reρ≤7/8之后。
- 图注：经典无零区域在高处向临界带边缘收窄；第17章所述2026 QRH结果则在全部高度给出Re(s)>7/8的固定无零半平面，s=1的极点须单独处理。由对称性，全部非平凡零点限制于1/8≤Reρ≤7/8。边界仍留在允许的闭带中；临界线1/2是RH的更强目标。
- 数学底线：左图完全是形状示意，采用任意显示函数w(y)=0.30/(1+4|y|)，不是任何经典显式区域、定理常数或低高度最佳结果。纵轴没有数值刻度，不能从图读取实际高度。右图横坐标准确，未放入任何零点数据。着色只在所画0≤σ≤1的部分显示，并不声称完整无零半平面止于1。
- 零点与极点：两侧浅绿区域不含点线边界；s=1用金色空圈标为极点，不能把它作为函数的普通非零值。图仅讨论非平凡零点，不展示负实轴的平凡零点。
- 依据：OpenAI，The Quasi-Riemann Hypothesis，署期2026-09-30，https://github.com/openai/math/blob/main/preprints/The-Quasi-Riemann-Hypothesis-September-30-2026/README.md ；正文第17章的完整范围说明。经典形状背景：https://arxiv.org/abs/2212.06867 。本图不构成对QRH整套证明的独立验证。
- 替代文本：两个并排临界带。左侧两条曲边向高处和低处收向0、1，浅绿排除区变窄。右侧1/8与7/8两条竖点线保留固定宽度的中间闭带，中央1/2青绿虚线标RH目标，s=1标极点。

## proof_scope_and_quantifiers.png / .svg

- 推荐位置：第18章“一行绿色字究竟说了什么”，量词与范围错译的例子之后。
- 图注：有限高度以内的验证不会自动覆盖无穷尾部。量词顺序也不能随意交换：“每个H都能选一个C使H≤C”成立，例如取C=H；“有一个C对全部正H都满足H≤C”不成立。内核检查给定命题与证明，数学审查还须确认给定命题表达了原来的目标。
- 数学底线：右图仅是正实数H、C的初等示例。对任意固定C>0，取H=C+1即为反例；没有对真实形式化工程提出错误指控。左侧点列是示意，不是零点表，不指某次实际验证结果。真实有限验证若配合另行证明的无限尾部论证，当然可能共同给出全称定理，本图只排除从有限检查本身直接跳到全称结论。
